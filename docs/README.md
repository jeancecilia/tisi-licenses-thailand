# Thai Industrial Standards Licenses (TISI) ETL

## Overview
This repository packages the publicly available license disclosures released by the Thai Industrial Standards Institute (TISI). Each monthly CSV snapshot (February 2024 onward) is merged, cleaned, and enriched to surface supply-chain signals such as import dependency, domestic exposure, and entrepreneur concentration. All downstream datasets are intended for economic research, market intelligence, and trade/supply-chain risk analysis.

- **Data source:** Thai Industrial Standards Institute (TISI)
- **License:** Creative Commons BY (CC BY 4.0)
- **Coverage:** Monthly snapshots from February 2024 through the latest available month

## Repository layout
```
tisi-licenses/
  data/
    raw/          # Drop TISI CSV snapshots here (e.g., tis_2024_02.csv)
    processed/    # Intermediate merged file generated by scripts/merge_raw.py
  datasets/       # Final Kaggle-ready outputs
  docs/           # README, column dictionary, Kaggle description
  scripts/
    merge_raw.py      # Step 1: Merge / normalize raw CSVs
    build_features.py # Step 2: Feature engineering + dataset generation
  requirements.txt
```

## Pipeline
1. **Populate `data/raw/`** with monthly CSV files named `tis_YYYY_MM.csv` (e.g., `tis_2024_02.csv`). Revised files can be tagged `tis_2025_06_rev1.csv`.
2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```
3. **Merge raw snapshots**
   ```bash
   python scripts/merge_raw.py
   ```
   - Reads every CSV in `data/raw/`
   - Normalizes column names to ASCII snake_case
   - Maps Thai headers to English canonical names (see column dictionary)
   - Adds `snapshot_date` inferred from the filename (first day of month)
   - Deduplicates exact matches
   - Writes `data/processed/tisi_licenses_merged.csv`
4. **Build feature datasets**
   ```bash
   python scripts/build_features.py
   ```
   - Ensures numeric types & fills missing totals
   - Calculates entrepreneur totals & multiple ratios
   - Generates five Kaggle-ready CSVs in `datasets/`

## Output datasets
| File | Description |
| --- | --- |
| `tisi_licenses_clean_2024_2025.csv` | Base tidy dataset with all license counts, entrepreneur totals, and ratio features for every TIS standard × month. |
| `tisi_trends_by_standard.csv` | Adds month-over-month absolute/pct deltas for each license category and the total. |
| `tisi_import_dependency.csv` | Focused view with manufacturing vs. import exposure per month. |
| `tisi_risk_index.csv` | Simple risk scoring that blends entrepreneur concentration with import dependency. |
| `tisi_latest_snapshot_summary.csv` | Latest month snapshot enriched with all ratios and risk scores for quick reporting. |

## Intended uses
- **Economic / market analysis:** Track Thai industrial capacity, licensing growth, and standard popularity over time.
- **Supply chain risk:** Identify standards with shrinking domestic participation or rising import reliance.
- **Trade/import dependency:** Quantify exposure to foreign sourcing via import-to-domestic ratios.
